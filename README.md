# Gate.io Futures Trading Bot

ربات معاملاتی خودکار برای صرافی Gate.io با استراتژی Trend State

## 🚀 ویژگی‌ها

- تحلیل ۱۲ ارز دیجیتال در تایم‌فریم ۵ دقیقه
- تایید سیگنال‌ها در تایم‌فریم ۱ ساعته
- سیستم امتیازدهی هوشمند سیگنال‌ها
- مدیریت ریسک پیشرفته
- فیلتر اخبار و احساسات بازار
- بک‌تست کامل قبل از اجرای زنده

## 📋 پیش‌نیازها

- Python 3.8+
- حساب KYC شده در Gate.io
- VPS با حداقل 2GB RAM
- دسترسی API با مجوز Trading
